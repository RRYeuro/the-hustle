# OG tester post rules (Chris, Nov 15)
- og-post.md gets posted to the OG channel every time it changes, so it must be REWRITTEN from scratch for every post.
- Only list what is new since the last OG post. Never keep the old items and add to them. If the last post said it, this one does not.
- New header line every time (the version and a different hook that matches what is in this drop). Do not reuse the last post's opening, thanks line or hook.
- Keep the short "how to refresh" line, nothing else carries over.
- Include the dev menu how-to only for the new features in this drop.
- Check git diff of og-post.md before pushing: the new file should share almost nothing with the old one.
